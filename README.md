# hshekhar.bhayanak.net

Personal portfolio site for [Himanshu Shekhar](https://hshekhar.bhayanak.net). Terminal/CLI aesthetic.

## Stack

- [Astro](https://astro.build) — static site generator
- [Tailwind CSS v4](https://tailwindcss.com) — styling
- [JetBrains Mono](https://www.jetbrains.com/lp/mono/) — font
- Tokyo Night Storm — color theme

## Features

- Terminal prompt aesthetic with `hshekhar@bhayanak ~ $` style sections
- Typewriter animation on load with fade-in content
- Blinking cursor that occasionally types dangerous commands and thinks better of it
- Fully static — no JS frameworks, no hydration

## Dev

```sh
pnpm install
pnpm dev       # localhost:4321
pnpm build     # output to dist/
pnpm preview   # preview production build
```
